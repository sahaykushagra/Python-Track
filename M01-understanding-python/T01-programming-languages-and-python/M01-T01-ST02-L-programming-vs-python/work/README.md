# Programming vs Programming Language

## What Is Programming?

Programming is the process of giving instructions to a computer to perform a specific task.

## What Is a Programming Language?

A programming language is a language used to write instructions that a computer can understand and execute.

## What Is Python?

Python is a popular, high-level programming language known for its simple and readable syntax.

## What Is Syntax?

Syntax is the set of rules that tells us how to write code correctly in a programming language.

## Programming and Python

Programming is the process of creating instructions, while Python is a programming language used to write those instructions.

## What Remained the Same?

The logic, conditions, and steps needed to solve the problem remained the same. Only the way the instructions were written changed.

## What Changed?

The pseudocode was converted into actual Python code using Python's syntax, keywords, and indentation rules so that the computer could execute it.

## My Final Understanding

Programming helps me: give instructions to a computer to solve problems.

Python helps me: write instructions in a simple and readable way.

Syntax tells me: the rules for writing code correctly.
