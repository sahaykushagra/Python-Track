# Why Programming Languages Exist

## Why Does a Computer Need Instructions?

A computer needs instructions because it cannot decide on its own what tasks to perform. It needs clear steps to do anything.

## Why Can We Not Build Applications Using Normal Human Language?

Normal human language can be ambiguous and confusing. Computers need instructions written in a structured language that they can understand.

## What Problem Do Programming Languages Solve?

Programming languages allow humans to communicate instructions to computers in a clear and organised way.

## Why Is Machine Language Difficult for Humans?

Machine language uses binary numbers like 0s and 1s, which are difficult for humans to read, write and understand.

## How Does Python Help?

Python allows us to write instructions using simple and readable syntax, making programming easier for humans.

## My Final Understanding

A programming language acts as a bridge between humans and computers.

Python allows a developer to: write clear instructions that a computer can understand and execute.

A computer follows: the instructions provided to it by a programmer.
